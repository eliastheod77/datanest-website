# Datanest Website

Design concepts and assets for the [Datanest](https://www.thedatanest.gr) website (built on Wix).

## Contents

- `hero-concept.html` — static mockup of a redesigned homepage hero section: a comic/pop-art styled dashboard graphic (replacing the original pop-art illustration) plus a trust-strip band, in Datanest's navy/gold/blue brand colors. Reference only — not production code; the real site is rebuilt manually inside the Wix Editor.

## Background

The live site is on Wix, so this repo isn't deployed code — it's a versioned history of design concepts and notes used to plan changes made directly in the Wix Editor.
